# Конфигуратор тумбы — 3D

Тестовое задание Qdesign.kz. Интерактивный 3D-конфигуратор тумбы на **React + Vite + Three.js**.
Размеры и материал меняются в панели — модель обновляется мгновенно.

## Соответствие заданию

| Пункт | Реализация |
|---|---|
| 3D-тумба на экране | Модель из деталей Three.js: корпус, верх, низ, боковины, задняя стенка, цоколь, полки, дверца с ручкой |
| 3 поля: ширина, высота, глубина (мм) | Модель обновляется сразу; проверка ввода, диапазон 200–2000 мм |
| Вращение и приближение мышью | OrbitControls с ограничениями (без переворота камеры и взгляда из-под пола) |
| Цвет: белый, серый, орех | `#F2F2F0`, `#888888`, `#805333`; у ореха — текстура древесины, нарисованная кодом |
| Свет и тени | Солнце через окно с мягкими динамическими тенями, отражённый свет окружения, затенение в углах (GTAO) |
| Доп.: размеры на модели | Размерные линии с подписями «Ш / В / Г» в мм, их можно скрыть |
| Доп.: дверца | Открывается кликом (касанием); от ширины 800 мм — две дверцы, как у реальной мебели |
| Доп.: телефон | Адаптивная вёрстка, управление пальцем |

Тумба стоит в комнате реальных пропорций (от 3,8 × 4,4 м, потолок 2,7 м; для крупной тумбы
комната становится просторнее) с окном, паркетом, плинтусами и люстрой.

- **Время суток** (07:00–21:00): солнце светит через окно, тени движутся вместе с ним, на закате
  свет тёплый, вечером включается люстра со своими тенями.
- **День / Ночь**: кнопки плавно переводят время на 13:00 или 21:00 — удобно для демонстрации.
- **Камера**, как в играх, упирается в стены, пол и потолок; кнопка «Исходный вид» возвращает ракурс.

## Запуск (Windows PowerShell)

```powershell
npm install      # установить зависимости
npm run dev      # режим разработки: http://localhost:5173
npm run lint     # проверка кода
npm run build    # production-сборка в папку dist
npm run preview  # просмотр сборки: http://localhost:4173
```

Требуется Node.js 18+.

## Структура

```
src/
  main.jsx                  точка входа React
  App.jsx                   состояние: размеры, материал
  config.js                 размеры по умолчанию, лимиты, цвета
  index.css                 стили и адаптивность
  utils/validation.js       проверка введённых размеров
  utils/time.js             формат времени и фаза дня
  hooks/useTimeOfDay.js     плавный переход времени для День / Ночь
  components/
    Viewer3D.jsx            мост React ↔ Three.js
    ControlPanel.jsx        панель параметров
    DimensionField.jsx      поле размера с проверкой ввода
    MaterialPicker.jsx      выбор материала
    TimeOfDayField.jsx      время суток: День / Ночь и ползунок
    ErrorBoundary.jsx       запасной экран, если 3D-сцена упала
  three/
    SceneManager.js         renderer, камера, свет, постобработка, дверцы, очистка
    daylight.js             расчёт солнца и света по времени суток
    createCabinet.js        сборка тумбы из деталей
    createRoom.js           комната: пол, стены, окно, плинтусы, люстра
    createDimensions.js     размерные линии и подписи
    materials.js            материалы (создаются один раз)
    woodTexture.js          текстура ореха на canvas
    parquetTexture.js       текстура паркета на canvas
```

## Публикация на Vercel

1. Загрузите проект в репозиторий GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → выберите репозиторий.
3. Vercel сам определит Vite (настройки также в `vercel.json`): build `npm run build`, output `dist`.
4. Нажмите **Deploy**.
